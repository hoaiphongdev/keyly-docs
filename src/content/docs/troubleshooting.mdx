## Keyly Not Showing Shortcuts

### Check Accessibility Permissions

<Steps>
1. Open **System Settings**
2. Go to **Privacy & Security → Accessibility**
3. Make sure **Keyly** is in the list and **enabled**
4. If not listed, try launching Keyly first
</Steps>

<Aside type="caution">
After enabling permissions, you may need to restart Keyly for changes to take effect.
</Aside>

### Restart Keyly

<Steps>
1. Click the **K icon** in the menu bar
2. Select **Quit**
3. Relaunch Keyly from Applications
</Steps>

## Shortcuts Window Not Appearing

### Double-Tap Caps Lock Quickly

Tap Caps Lock **twice within half a second**. macOS ignores very short Caps Lock taps, so press each tap fully. If you remapped Caps Lock in **System Settings → Keyboard → Modifier Keys**, set a different `super_key` in `~/.config/keyly/setting.conf`. If `super_key` is set to something Keyly can't read, it falls back to the default (Caps Lock) and lists the problem under **⚙︎ → ⚠︎ config problems** in the shortcuts window.

### Caps Lock Switches Input Source

If **Use the Caps Lock key to switch to and from ABC** is turned on (**System Settings → Keyboard → Input Sources → Edit…**), macOS uses Caps Lock to switch input sources instead of toggling it, so a double-tap may not register. Turn that option off, or set a different `super_key` in `~/.config/keyly/setting.conf`.

### Check If App Has Menu Bar

Some apps (especially games or full-screen apps) may not expose their shortcuts via the menu bar. Keyly can only read what's accessible through the Accessibility API.

## Some Shortcuts Are Missing

### Not All Shortcuts Can Be Detected

This is a macOS limitation, not a bug. Some shortcuts are **internal** — the app handles them directly without going through macOS.

For example, VS Code's `⌘P` (Quick Open) or `⌘⇧P` (Command Palette) are internal shortcuts that macOS can't see.

<Aside>
Learn more about this in [Why Some Shortcuts Can't Be Detected](/resources/detection-limits/).
</Aside>

### Solution: Use Custom Configurations

You can manually add any missing shortcuts:

1. **Use a template** — Check [Templates](/configuration/templates/) for pre-made configs
2. **Create your own** — See [Custom Shortcuts](/configuration/custom-shortcuts/)

## Custom Shortcuts Not Working

### Verify File Location

Make sure your `.keyly` file is in:
```
~/.config/keyly/templates/
```

### Check the Problems List

Open the shortcuts window and click **⚙︎ → ⚠︎ config problems**. Every line Keyly couldn't read is listed with its file and line number; click one to open it.

### Check the App Line

The `# App:` header can be the app's name, its bundle id or its full path:

```keyly
# App: Safari
```

Find an app's bundle id:
```bash
osascript -e 'id of app "Safari"'
```

## Template Not Working After Installation

<Aside type="caution">
Templates point to the app's usual location. Keyly also matches them by the app's name, so apps in `~/Applications`, apps from Setapp and newer yearly versions (Photoshop 2025 for a 2024 template) work without changes.
</Aside>

### App Name Mismatch

A template can still miss your app when **its name is different**, for example `Cursor - Nightly` instead of `Cursor`.

### How to Fix

<Steps>
1. Check **⚙︎ → ⚠︎ config problems** in the shortcuts window
2. Open the template file in `~/.config/keyly/templates/`
3. Change the `# App:` line to your app's name or bundle id
</Steps>

Example:
```keyly
# Template default
# App: /Applications/Cursor.app

# Your app's name
# App: Cursor - Nightly
```

Keyly reloads the file automatically when you save it. If the change doesn't show, use **⚙︎ → Reload Config** in the shortcuts window

### Reload Keyly

Config files reload automatically when you save them. To reload manually, use **⚙︎ → Reload Config** in the shortcuts window

### Check File Encoding

Save your `.keyly` file as **UTF-8** (with or without BOM). Characters Keyly can't decode show as `�`, and the rest of the file still loads.

## Menu Bar Icon Missing

### Check Menu Bar Space

If you have many menu bar items, Keyly's icon might be hidden. Try:
- Holding ⌘ and dragging icons to rearrange
- Using an app like Bartender or Hidden Bar to manage menu bar items

### Verify Keyly Is Running

Open Activity Monitor and search for "Keyly". If not running, launch it from Applications.

## App Crashes or Freezes

### Check macOS Version

Keyly requires **macOS 12.0 or later** on a Mac with Apple silicon. Check your Mac:
1. Click  → About This Mac
2. Check the macOS version, and that **Chip** shows Apple M1 or newer

### Reset Keyly

Remove config and restart:
```bash
rm -rf ~/.config/keyly
```

Then relaunch Keyly.

## Updates

Keyly checks for updates every 6 hours. When a new version is out, the menu bar icon shows a red dot and the menu gets an **Update to x.y.z…** item. You can also use **Check for Updates...** at any time.

### Upgrading from 1.7.3 or Older

Versions up to 1.7.3 have no updater. Upgrade once manually:

<Steps>
1. Run the install command from [Getting Started](/getting-started/) again
2. Grant **Accessibility** permission again (the app's signing changed)
3. From then on, updates install automatically and keep the permission
</Steps>

### "Keyly cannot be opened" on First Launch

Keyly is not notarized by Apple. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. This is only needed once; updates are not affected.
