## UI & Display

### Multi-Column Layout

Shortcuts are organized in a clean multi-column layout for easy scanning.

### Category Grouping

Shortcuts are grouped by menu category (File, Edit, View, etc.) just like in the app's menu bar.

### Instant Search

Start typing in the shortcuts window to filter by action, category or key. The first ESC clears the search; the next one closes the window.

### Category Descriptions

Add contextual hints below category titles using `> description` syntax in your [custom shortcuts](/configuration/custom-shortcuts/).

### Blur Effect Overlay

A beautiful floating window with backdrop blur appears over your current app, keeping context visible.

## Menus

The **K icon** in your menu bar gives quick access to:

| Option | Description |
|--------|-------------|
| **About Keyly** | Version and app info |
| **Check for Updates...** | Look for a new version |
| **Quit** | Exit Keyly |

The **⚙︎ button** in the shortcuts window adds:

| Option | Description |
|--------|-------------|
| **Reload Config** | Reload your custom `.keyly` files |
| **Open Config Folder** | Open `~/.config/keyly/` folder for custom configs |
| **Open Accessibility Settings** | Quick link to macOS permissions |
| **Check for Updates...** | Look for a new version |
| **Quit Keyly** | Exit Keyly |

## Technical Details

- **Built with Swift 5.9+**
- **Requires macOS 12.0+**
- **Uses Accessibility API** for shortcut extraction
- **Low memory footprint** — runs quietly in the menu bar
