Keyly có thể tùy chỉnh thông qua file cấu hình `.keyly` lưu trong `~/.config/keyly/templates/`.

## Vị trí cấu hình

Tất cả file phím tắt tùy chỉnh được lưu trong:

```
~/.config/keyly/templates/
```

Mở nhanh thư mục cấu hình (`~/.config/keyly/`, chứa `templates/` và `setting.conf`) từ cửa sổ phím tắt: **nút ⚙︎ → Open Config Folder**

## Cách hoạt động

1. Tạo file `.keyly` trong `~/.config/keyly/templates/`
2. Khai báo phím tắt theo danh mục và tổ hợp phím
3. Keyly gộp phím tắt tùy chỉnh với phím tắt gốc của ứng dụng
4. Nhấn đúp Caps Lock để xem tất cả cùng nhau

## Ví dụ nhanh

Tạo file `~/.config/keyly/templates/safari.keyly`:

```keyly
# Sheet Name: Safari nâng cao
# App: Safari

[Điều hướng]
CMD+L       Mở thanh địa chỉ
CMD+T       Tab mới
CMD+SHIFT+T Mở lại tab vừa đóng
```

Xem [Phím tắt tùy chỉnh](/vi/configuration/custom-shortcuts/) để biết đầy đủ cú pháp, hoặc cài [mẫu có sẵn](/vi/configuration/templates/) để dùng cấu hình soạn sẵn.

## Cài đặt

File `~/.config/keyly/setting.conf` quyết định cách mở Keyly. Keyly tự tạo file này ở lần mở đầu tiên, ghi sẵn mọi tùy chọn nhưng đang tắt bằng dấu `#` ở đầu dòng. Xóa dấu `#` ở dòng nào thì dòng đó có hiệu lực. Thay đổi áp dụng ngay khi bạn lưu.

```ini
super_key = ctrl+k
trigger_type = hold
hold_duration = 400ms
```

| Cài đặt | Tác dụng | Giá trị |
|---------|----------|---------|
| `super_key` | Phím mở Keyly | `capslock` (mặc định), một phím bổ trợ đứng riêng như `cmd`, hoặc tổ hợp như `ctrl+k`, `Command + Shift + K`, `⌃⌥Space`. Tên phím bổ trợ: `cmd`/`command`/`⌘`, `ctrl`/`control`/`⌃`, `alt`/`opt`/`option`/`⌥`, `shift`/`⇧`, `fn` |
| `trigger_type` | Cách dùng phím đó | `press` là nhấn liên tiếp `press_count` lần, `hold` là giữ trong `hold_duration`. Caps Lock chỉ dùng được kiểu nhấn; phím khác mặc định là giữ, trừ khi bạn đặt `press` |
| `press_count` | Số lần nhấn liên tiếp với `press` | Từ `1` đến `4` (mặc định `2`), mỗi lần cách lần trước không quá nửa giây |
| `hold_duration` | Thời gian giữ với `hold` | `0.5`, `0.5s` hoặc `500ms`, từ `0.1s` đến `3s` (mặc định `0.5`) |
| `screen_width_ratio` | Độ rộng tối đa của cửa sổ phím tắt so với màn hình | Từ `0.1` đến `1.0`, hoặc phần trăm như `70%` (mặc định `0.7`) |

Cài đặt rất dễ tính:

- Tên và giá trị không phân biệt chữ hoa chữ thường; dấu ngoặc kép hay ghi chú `# ...` ở cuối dòng đều không sao.
- Số nằm ngoài khoảng cho phép sẽ dùng giá trị gần nhất, ví dụ `hold_duration = 10` thành giữ 3 giây.
- Giá trị nào Keyly không đọc được sẽ dùng mặc định và hiện trong **nút ⚙︎ → ⚠︎ config problems** của cửa sổ phím tắt. Gõ sai tên sẽ được gợi ý, ví dụ "Did you mean hold_duration?".

<Aside type="tip" title="Dùng riêng một phím bổ trợ">
Với `super_key = cmd` và `trigger_type = press`, một lần nhấn chỉ được tính khi bạn thả ⌘ ra, và chỉ khi bạn không bấm thêm phím nào khác. Dùng ⌘C hay ⌘⇧ sẽ không bao giờ mở Keyly, kể cả khi `press_count = 1`.
</Aside>

Một vài phím có nghĩa cố định: `enter` là phím Return (dùng `keypad enter` cho phím Enter trên bàn phím số), `del` là phím ⌫. Không ghép được `fn` với phím mũi tên, F1–F12, Home, End, Page Up hay Page Down, vì macOS tự gắn fn cho các phím này.
