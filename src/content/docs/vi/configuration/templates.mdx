Mẫu (template) là các file `.keyly` do cộng đồng soạn sẵn cho các ứng dụng phổ biến. Cài đặt chỉ với một lệnh.

## Cài đặt nhanh

Dùng script cài mẫu để tải về từ GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly
```

Lệnh này cài mẫu cho Cursor IDE vào `~/.config/keyly/templates/cursor.keyly`.

## Các mẫu hiện có

Xem tất cả mẫu trên GitHub:

👉 **[Xem tất cả mẫu](https://github.com/hoaiphongdev/keyly/tree/main/templates)**

<Aside type="tip">
Muốn đóng góp mẫu? Xem [Tạo mẫu mới](#tạo-mẫu-mới) bên dưới.
</Aside>

<Aside type="caution" title="Mẫu có thể chưa chạy ngay">
Một số mẫu có thể chưa chạy ngay vì **đường dẫn ứng dụng** trên máy Mac của bạn có thể khác.

Vị trí ứng dụng có thể khác do:
- Cách cài khác nhau (App Store hay tải trực tiếp)
- Phiên bản mới đổi tên file `.app`
- Ứng dụng được cài ở thư mục khác

**Nếu mẫu không chạy sau khi cài:**
1. Mở file `.keyly` trong `~/.config/keyly/templates/`
2. Tìm dòng `# App:` ở đầu file
3. Sửa lại đường dẫn cho đúng vị trí thật của ứng dụng

```bash
# Tìm đường dẫn đúng của ứng dụng
ls /Applications/*.app
# Hoặc với ứng dụng cài riêng cho người dùng
ls ~/Applications/*.app
```

Ví dụ sửa:
```keyly
# Trước (mặc định của mẫu)
# App: /Applications/Cursor.app

# Sau (đường dẫn thật trên máy bạn)
# App: /Applications/Cursor - Nightly.app
```
</Aside>

## Tùy chọn cài đặt

### Tham số bắt buộc

| Tham số | Mô tả | Ví dụ |
|---------|-------|-------|
| `-t <tên>` | Tên mẫu (bắt buộc) | `-t cursor.keyly` |

### Tham số tùy chọn

| Tham số | Mô tả | Ví dụ |
|---------|-------|-------|
| `-n <tên file>` | Đặt tên file khác | `-n my-cursor.keyly` |
| `-f` | Ghi đè file đã có | `-f` |

## Ví dụ

### Cài đặt cơ bản

```bash
# Cài mẫu Cursor
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly
```

### Đặt tên file khác

```bash
# Cài với tên file tùy chọn
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly -n cursor-custom.keyly
```

### Ghi đè file cũ

```bash
# Ghi đè file đã có cùng tên
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly -f
```

## Quy trình cài đặt

<Steps>
1. Script kiểm tra tên mẫu
2. Tải mẫu từ GitHub
3. Nếu đã có file cùng tên, script dừng lại, báo lỗi và gợi ý dùng `-f` (có `-f` thì file cũ bị ghi đè)
4. Lưu vào `~/.config/keyly/templates/`
5. Sẵn sàng dùng — nhấn đúp Caps Lock để xem phím tắt
</Steps>

## Định dạng mẫu

Mẫu dùng định dạng `.keyly` chuẩn, có thêm **mô tả danh mục**.

```keyly
# Sheet Name: Cursor IDE
# App: /Applications/Cursor.app

[Chat]
> Đặt con trỏ vào khung chat trước.
CMD+L       Mở khung chat
CMD+I       Mở Composer
CMD+SHIFT+I Mở Composer ngay trong trình soạn thảo

[Trình soạn thảo]
> Các phím tắt chỉnh sửa cơ bản.
CMD+D       Chọn lần xuất hiện tiếp theo
CMD+SHIFT+L Chọn tất cả lần xuất hiện
```

Dòng `> mô tả` sau `[Danh mục]` thêm gợi ý hiển thị dưới tiêu đề danh mục trong cửa sổ phím tắt.

## Tạo mẫu mới

Muốn tạo mẫu cho ứng dụng bạn yêu thích?

<Steps>
1. Tạo file `.keyly` theo [cú pháp phím tắt tùy chỉnh](/vi/configuration/custom-shortcuts/)
2. Thêm mô tả danh mục bằng `> gợi ý` để có ngữ cảnh
3. Chạy thử trên máy trong `~/.config/keyly/templates/`
4. Gửi pull request tới [kho mã Keyly](https://github.com/hoaiphongdev/keyly)
</Steps>

### Hướng dẫn soạn mẫu

- Dùng tên danh mục rõ ràng, dễ hiểu
- Thêm gợi ý `> mô tả` để có ngữ cảnh
- Đưa vào các phím tắt hay dùng
- Thử với ứng dụng thật
- Đặt tên file theo quy ước: `tên-ứng-dụng.keyly`
