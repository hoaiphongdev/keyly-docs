Tạo file `.keyly` trong `~/.config/keyly/` để thêm phím tắt tùy chỉnh cho bất kỳ ứng dụng nào.

## Vị trí file

```
~/.config/keyly/
├── safari.keyly
├── vscode.keyly
├── my-shortcuts.keyly
└── ...
```

<Aside type="tip">
Mở nhanh thư mục này: click **nút ⚙︎** trong cửa sổ phím tắt → **Open Config Folder**
</Aside>

## Định dạng file

```
# Sheet Name: Phím tắt của tôi
# App: /Applications/Safari.app

[Tên danh mục]
> Mô tả tùy chọn cho danh mục này
CMD+K       Mô tả phím tắt
CMD+SHIFT+K Một phím tắt khác
```

### Phần đầu file

| Trường | Bắt buộc | Mô tả |
|--------|----------|-------|
| `# Sheet Name:` | Không | Tên hiển thị trong cửa sổ phím tắt |
| `# App:` | **Có** | Đường dẫn đầy đủ tới ứng dụng (file `.app`) |

### Các phím bổ trợ

| Phím bổ trợ | Ký hiệu |
|-------------|---------|
| `CMD` | ⌘ Command |
| `SHIFT` | ⇧ Shift |
| `OPT` hoặc `ALT` | ⌥ Option |
| `CTRL` | ⌃ Control |

Nối các phím bổ trợ bằng dấu `+`:
- `CMD+C` → ⌘C
- `CMD+SHIFT+T` → ⌘⇧T
- `CMD+OPT+ESC` → ⌘⌥⎋

## Mô tả danh mục

Thêm một dòng mô tả ngay sau `[Danh mục]`, bắt đầu bằng dấu `>`:

```
[Chat]
> Đặt con trỏ vào khung chat trước.
CMD+L       Mở khung chat
CMD+I       Mở Composer
```

Mô tả hiển thị như tiêu đề phụ dưới tên danh mục trong cửa sổ phím tắt. Rất hữu ích để thêm gợi ý ngữ cảnh.

## Ví dụ đầy đủ

```
# Sheet Name: Phím tắt của tôi
# App: /Applications/Safari.app

[Điều hướng]
> Các phím tắt điều hướng cơ bản
CMD+L       Mở thanh địa chỉ
CMD+T       Tab mới
CMD+SHIFT+T Mở lại tab vừa đóng
CMD+[       Quay lại
CMD+]       Tiến tới

[Dấu trang]
> Quản lý dấu trang
CMD+D       Thêm dấu trang
CMD+SHIFT+B Xem tất cả dấu trang

[Tab]
> Quản lý tab
CTRL+TAB    Tab kế tiếp
CTRL+SHIFT+TAB Tab trước đó
CMD+W       Đóng tab
CMD+SHIFT+W Đóng cửa sổ
```

## Tạo file cấu hình

<Steps>
1. Mở Terminal

2. Tạo thư mục cấu hình (nếu chưa có):
   ```bash
   mkdir -p ~/.config/keyly
   ```

3. Tạo file `.keyly` mới:
   ```bash
   nano ~/.config/keyly/myapp.keyly
   ```

4. Thêm phím tắt theo định dạng ở trên

5. Lưu file và tải lại bằng **nút ⚙︎ → Reload Config** trong cửa sổ phím tắt
</Steps>

## Mẹo hay

- **Mỗi file cho một ứng dụng** giúp gọn gàng hơn, còn tên file thì đặt tùy ý
- **Danh mục** giúp nhóm các phím tắt liên quan (dùng cú pháp `[Tên danh mục]`)
- **Chú thích** bắt đầu bằng `#` và sẽ bị bỏ qua
- **Khoảng trắng** giữa tổ hợp phím và mô tả rất linh hoạt (dấu cách hoặc tab đều được)
- **Tải lại** Keyly sau khi sửa cấu hình để thấy thay đổi

## Xử lý sự cố

### Phím tắt không xuất hiện?

1. Kiểm tra đường dẫn `# App:` có đúng không
2. Đảm bảo ứng dụng thật sự nằm ở đường dẫn đó
3. Tải lại bằng **nút ⚙︎ → Reload Config** trong cửa sổ phím tắt
4. Kiểm tra file được lưu với bảng mã UTF-8

### Đường dẫn ứng dụng bị sai?

Tìm đường dẫn đúng:
```bash
ls /Applications/*.app
# hoặc ứng dụng cài riêng cho người dùng
ls ~/Applications/*.app
```

## Dùng mẫu có sẵn

Không muốn viết cấu hình từ đầu? Dùng mẫu do cộng đồng soạn:

```bash
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor
```
