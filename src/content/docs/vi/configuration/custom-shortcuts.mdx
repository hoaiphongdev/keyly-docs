Tạo file `.keyly` trong `~/.config/keyly/` để thêm phím tắt tùy chỉnh cho bất kỳ ứng dụng nào.

## Vị trí file

```
~/.config/keyly/
├── safari.keyly
├── vscode.keyly
├── my-shortcuts.keyly
└── ...
```

<Aside type="tip">
Mở nhanh thư mục này: click **biểu tượng ⌘** ở menu bar → **Open Config**
</Aside>

## Định dạng file

```
# Sheet Name: Phím tắt của tôi
# App: /Applications/Safari.app

[Tên danh mục]
> Mô tả tùy chọn cho danh mục này
KEY+COMBO   Mô tả phím tắt
KEY+COMBO   Phím tắt khác
```

### Header

| Trường | Bắt buộc | Mô tả |
|--------|----------|-------|
| `# Sheet Name:` | Tùy chọn | Tên hiển thị trong overlay |
| `# App:` | **Bắt buộc** | Đường dẫn đầy đủ tới app bundle |

### Các phím modifier

| Modifier | Ký hiệu |
|----------|---------|
| `CMD` | ⌘ Command |
| `SHIFT` | ⇧ Shift |
| `OPT` hoặc `ALT` | ⌥ Option |
| `CTRL` | ⌃ Control |

Kết hợp modifier bằng `+`:
- `CMD+C` → ⌘C
- `CMD+SHIFT+T` → ⌘⇧T
- `CMD+OPT+ESC` → ⌘⌥⎋

## Mô tả danh mục

Thêm dòng mô tả sau `[Danh mục]` bằng prefix `>`:

```
[Chat]
> Focus vào panel chat trước.
CMD+L       Focus Chat
CMD+I       Mở Composer
```

Mô tả sẽ hiển thị như tiêu đề phụ dưới tên danh mục trong cửa sổ phím tắt. Rất hữu ích để thêm gợi ý ngữ cảnh.

## Ví dụ đầy đủ

```
# Sheet Name: Phím tắt của tôi
# App: /Applications/Safari.app

[Navigation]
> Các phím tắt điều hướng cơ bản
CMD+L       Mở thanh địa chỉ
CMD+T       Tab mới
CMD+SHIFT+T Mở lại tab vừa đóng
CMD+[       Quay lại
CMD+]       Tiến tới

[Bookmarks]
> Quản lý bookmark
CMD+D       Thêm Bookmark
CMD+SHIFT+B Xem tất cả Bookmark

[Tabs]
> Quản lý tab
CTRL+TAB    Tab kế tiếp
CTRL+SHIFT+TAB Tab trước đó
CMD+W       Đóng tab
CMD+SHIFT+W Đóng cửa sổ
```

## Tạo file config

<Steps>
1. Mở Terminal

2. Tạo thư mục config (nếu chưa có):
   ```bash
   mkdir -p ~/.config/keyly
   ```

3. Tạo file `.keyly` mới:
   ```bash
   nano ~/.config/keyly/myapp.keyly
   ```

4. Thêm phím tắt theo định dạng trên

5. Lưu file và reload Keyly từ menu bar
</Steps>

## Mẹo hay

- **Mỗi file một app** giúp gọn gàng hơn, nhưng bạn có thể đặt tên tùy ý
- **Danh mục** giúp nhóm phím tắt liên quan (dùng cú pháp `[Tên danh mục]`)
- **Comment** bắt đầu bằng `#` và sẽ bị bỏ qua
- **Khoảng trắng** giữa tổ hợp phím và mô tả linh hoạt (space hoặc tab đều được)
- **Reload** Keyly sau khi sửa config để thấy thay đổi

## Xử lý sự cố

### Phím tắt không xuất hiện?

1. Kiểm tra đường dẫn `# App:` có đúng không
2. Đảm bảo app bundle tồn tại ở đường dẫn đó
3. Reload Keyly từ menu bar
4. Kiểm tra encoding file là UTF-8

### Đường dẫn app bundle sai?

Tìm đường dẫn đúng:
```bash
ls /Applications/*.app
# hoặc app cài trong user
ls ~/Applications/*.app
```

## Dùng Templates

Không muốn viết config từ đầu? Dùng template cộng đồng:

```bash
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor
```

Xem [Templates](/vi/configuration/templates/) để biết các template có sẵn.
