Làm chủ phím tắt và tăng năng suất trên macOS với những mẹo sau.

## Bắt đầu nhỏ

Đừng cố nhớ hết phím tắt cùng lúc. Chọn 2-3 phím tắt mỗi app mà bạn dùng nhiều nhất.

<Aside type="tip">
Dùng Keyly để khám phá phím tắt có sẵn, rồi tập trung học những cái bạn thực sự dùng.
</Aside>

## Quy tắc 80/20

Tập trung vào 20% phím tắt bạn sẽ dùng 80% thời gian:

| Phím tắt | Hành động |
|----------|-----------|
| `⌘C` / `⌘V` | Copy / Paste |
| `⌘Z` | Undo |
| `⌘⇧Z` | Redo |
| `⌘Tab` | Chuyển app |
| `⌘Space` | Tìm kiếm Spotlight |
| `⌘W` | Đóng cửa sổ/tab |
| `⌘Q` | Thoát app |
| `⌘S` | Lưu |
| `⌘F` | Tìm kiếm |

## Học theo từng App

Chọn một app bạn dùng hằng ngày và cam kết dùng phím tắt trong một tuần:

### Finder
- `⌘N` — Cửa sổ Finder mới
- `⌘⇧N` — Thư mục mới
- `Space` — Quick Look
- `⌘⌫` — Chuyển vào Thùng rác

### Safari / Chrome
- `⌘T` — Tab mới
- `⌘W` — Đóng tab
- `⌘L` — Focus thanh địa chỉ
- `⌘⇧T` — Mở lại tab vừa đóng

### VS Code / Editor
- `⌘P` — Mở file nhanh
- `⌘⇧P` — Command palette
- `⌘D` — Chọn lần xuất hiện tiếp theo
- `⌘/` — Bật/tắt comment

## Xây dựng Muscle Memory

1. **Xem nó** — Giữ ⌘ 2 giây để xem phím tắt với Keyly
2. **Dùng nó** — Ép bản thân dùng phím tắt thay vì chuột
3. **Lặp lại** — Làm như vậy 3-5 ngày cho đến khi thành tự động
