## Yêu cầu

- **macOS 12.0+** (Monterey trở lên)
- **Máy Mac dùng chip Apple** (M1 trở lên)
- Quyền Trợ năng (Accessibility)

## Cài đặt

<Steps>
1. Mở ứng dụng dòng lệnh (Terminal, iTerm, Warp đều được)

2. Chạy lệnh này:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install.sh | bash
   ```

3. Làm theo hướng dẫn để cấp quyền Trợ năng

4. Xong! Nhấn đúp `⇪ Caps Lock` để xem phím tắt
</Steps>

### Cài bằng Homebrew

Nếu bạn dùng [Homebrew](https://brew.sh), chạy lệnh này thay cho lệnh trên:

```bash
brew install --cask hoaiphongdev/keyly/keyly
```

Đã cài Keyly bằng lệnh `curl`? Chạy `brew install --cask --adopt hoaiphongdev/keyly/keyly` để Homebrew quản lý luôn app đang có. Dù cài cách nào, Keyly vẫn tự cập nhật.

## Cấp quyền Trợ năng

Keyly cần quyền Trợ năng (Accessibility) để:

1. **Theo dõi phím bấm** — nhận biết khi bạn nhấn đúp Caps Lock
2. **Đọc thanh menu** — lấy phím tắt từ các ứng dụng khác

<Steps>
1. Mở **Cài đặt hệ thống** (System Settings)
2. Vào **Quyền riêng tư & Bảo mật → Trợ năng** (Privacy & Security → Accessibility)
3. Tìm **Keyly** trong danh sách và bật lên
4. Khởi động lại Keyly nếu cần
</Steps>

<Aside type="tip">
Nếu không thấy Keyly trong danh sách, thử mở Keyly trước rồi kiểm tra lại.
</Aside>

## Cách sử dụng

<Steps>
1. Mở Keyly — biểu tượng **K** sẽ xuất hiện trên thanh menu
2. Mở ứng dụng bất kỳ (Safari, VS Code, Finder,...)
3. Nhấn đúp phím **Caps Lock (⇪)**
4. Một cửa sổ hiển thị tất cả phím tắt sẽ xuất hiện
5. Gõ phím để lọc phím tắt — bấm ESC một lần để xóa nội dung tìm kiếm
6. Bấm ESC (thêm lần nữa) hoặc click ra ngoài để ẩn cửa sổ
</Steps>

## Các menu

Click **biểu tượng K** trên thanh menu để xem:

- **About Keyly** — Thông tin phiên bản
- **Check for Updates...** — Kiểm tra bản mới
- **Quit** — Thoát Keyly

Click **nút ⚙︎** ở góc dưới bên phải cửa sổ phím tắt để xem:

- **Reload Config** — Tải lại các file `.keyly`
- **Open Config Folder** — Mở thư mục `~/.config/keyly/`
- **Open Accessibility Settings** — Mở phần cài đặt quyền Trợ năng
- **Check for Updates...** — Kiểm tra bản mới
- **Quit Keyly** — Thoát Keyly

## Gỡ cài đặt

### Đã cài bằng Homebrew

```bash
brew uninstall --cask keyly          # gỡ app, giữ lại cài đặt của bạn
brew uninstall --cask --zap keyly    # gỡ luôn cài đặt và phím tắt tự viết
```

### Đã cài bằng lệnh curl

<Steps>
1. Thoát Keyly: bấm **biểu tượng K** trên thanh menu → **Quit**
2. Kéo **Keyly** trong **Applications** vào Thùng rác, hoặc chạy:

   ```bash
   rm -rf /Applications/Keyly.app
   ```
</Steps>

### Xoá Keyly khỏi danh sách Trợ năng

Dù cài bằng cách nào, macOS vẫn giữ Keyly trong danh sách Trợ năng cho tới khi bạn xoá:

```bash
tccutil reset Accessibility com.keyly.app
```

Hoặc mở **System Settings → Privacy & Security → Accessibility**, chọn **Keyly** rồi bấm **−**.

### Xoá cài đặt và phím tắt tự viết (không bắt buộc)

Bỏ qua bước này nếu bạn đã dùng `brew uninstall --zap`, vì lệnh đó đã xoá rồi.

```bash
rm -rf ~/.config/keyly
rm -rf ~/Library/Caches/com.keyly.app ~/Library/Caches/com.keyly.app.sparkle ~/Library/HTTPStorages/com.keyly.app*
defaults delete com.keyly.app
```

<Aside type="caution">
`~/.config/keyly` chứa các bảng phím tắt bạn tự viết. Hãy chép ra chỗ khác trước nếu muốn giữ lại.
</Aside>
