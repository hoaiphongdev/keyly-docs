## General

### Is Keyly free?

Yes, Keyly is completely free and open source under the MIT license.

### Which macOS versions are supported?

macOS 12.0 (Monterey) and later, on a Mac with Apple silicon (M1 or newer).

### How is Keyly different from CheatSheet, KeyCue or KeyClu?

All four show the shortcuts of the app you are using. Keyly is free and open source, opens with a double-tap of Caps Lock or any key you choose, and keeps your own shortcuts in plain text files. See the [side-by-side comparison](/compare/).

### Is Keyly safe? Why does it need Accessibility permissions?

Keyly uses Accessibility permissions for two things:
1. **Detect when you double-tap ⇪ Caps Lock** — to trigger the shortcut overlay
2. **Read menu bar shortcuts** — to extract shortcuts from other apps

Keyly does not log keystrokes, send data anywhere, or access anything beyond what's needed to show shortcuts.

## Usage

### How do I show the shortcuts overlay?

Double-tap the **⇪ Caps Lock** key. Press **ESC** or click outside to hide (if you typed in the search field, the first ESC clears the search).

### Why don't I see all shortcuts for some apps?

Not all shortcuts can be detected — this is a macOS limitation. Some shortcuts are **internal** to the app and invisible to macOS.

For example, VS Code's Command Palette (`⌘⇧P`) is an internal shortcut that macOS can't see.

**Solution:** Use [custom configurations](/configuration/custom-shortcuts/) or install a [community template](/configuration/templates/).

See [Why Some Shortcuts Can't Be Detected](/resources/detection-limits/) for a detailed explanation.

### Can I change the trigger key or delay?

Yes. Edit `~/.config/keyly/setting.conf` (Keyly creates it on first launch, with every option commented out) and set `super_key` (e.g. `cmd`, `ctrl+k`, `Command + Shift + K`) and `trigger_type` (`hold` or `press`), plus `hold_duration` (e.g. `0.5` or `500ms`) or `press_count`. If a value can't be read, Keyly keeps working with the default and lists the problem under **⚙︎ → ⚠︎ config problems**. The default is double-tapping Caps Lock because it rarely clashes with other shortcuts. See [Settings](/configuration/#settings) for every option.

### Does Keyly work with custom/non-standard apps?

Keyly works with any app that has a standard macOS menu bar. For apps without menu bars, use [custom shortcut configs](/configuration/custom-shortcuts/).

## Custom Shortcuts

### Where do I put custom shortcut files?

In `~/.config/keyly/templates/`. Open the config folder quickly via the **⚙︎ button in the shortcuts window → Open Config Folder** (it opens `~/.config/keyly/`, which contains `templates/`).

### Can I add shortcuts for multiple apps in one file?

Each `.keyly` file should target one app (specified in the `# App:` header). Create separate files for different apps.

### How do I reload after editing configs?

Keyly reloads config files automatically when you save them. To reload manually, click the **⚙︎ button** in the shortcuts window and select **Reload Config**.

### Why doesn't the template work after installation?

Keyly matches a template by its app path, and by the app's name when the path is different, so apps in `~/Applications`, apps from Setapp and newer yearly versions are found. A template can still miss an app whose name is different, such as `Cursor - Nightly`.

**Fix:** Check **⚙︎ → ⚠︎ config problems** in the shortcuts window. Then open the `.keyly` file in `~/.config/keyly/templates/` and change the `# App:` line to your app's name (`# App: Cursor - Nightly`) or bundle id.

See [Troubleshooting → Template Not Working](/troubleshooting/#template-not-working-after-installation) for detailed steps.

## Troubleshooting

### Keyly isn't working at all

See the [Troubleshooting guide](/troubleshooting/) for step-by-step solutions.

### How do I uninstall Keyly?

Run `brew uninstall --cask keyly` if you installed with Homebrew, or quit Keyly and delete it from Applications. See [Uninstall](/getting-started/#uninstall) for removing the Accessibility entry and your settings too.

### I found a bug / have a feature request

Please [open an issue on GitHub](https://github.com/hoaiphongdev/keyly/issues).
