## General

### Is Keyly free?

Yes, Keyly is completely free and open source under the Apache 2.0 license.

### Which macOS versions are supported?

macOS 12.0 (Monterey) and later.

### Is Keyly safe? Why does it need Accessibility permissions?

Keyly uses Accessibility permissions for two things:
1. **Detect when you double-tap ⇪ Caps Lock** — to trigger the shortcut overlay
2. **Read menu bar shortcuts** — to extract shortcuts from other apps

Keyly does not log keystrokes, send data anywhere, or access anything beyond what's needed to show shortcuts.

## Usage

### How do I show the shortcuts overlay?

Double-tap the **⇪ Caps Lock** key. Press **ESC** or click outside to hide.

### Why don't I see all shortcuts for some apps?

Not all shortcuts can be detected — this is a macOS limitation. Some shortcuts are **internal** to the app and invisible to macOS.

For example, VS Code's Command Palette (`⌘⇧P`) is an internal shortcut that macOS can't see.

**Solution:** Use [custom configurations](/configuration/custom-shortcuts/) or install a [community template](/configuration/templates/).

See [Why Some Shortcuts Can't Be Detected](/resources/detection-limits/) for a detailed explanation.

### Can I change the trigger key or delay?

Yes. Edit `~/.config/keyly/setting.conf` and set `super_key` (e.g. `cmd`, `alt`, `ctrl+alt`) and `trigger_type` (`hold` or `press`), plus `hold_duration` or `press_count`. The default is double-tapping Caps Lock because it rarely clashes with other shortcuts.

### Does Keyly work with custom/non-standard apps?

Keyly works with any app that has a standard macOS menu bar. For apps without menu bars, use [custom shortcut configs](/configuration/custom-shortcuts/).

## Custom Shortcuts

### Where do I put custom shortcut files?

In `~/.config/keyly/`. Open this folder quickly via the **⚙︎ button in the shortcuts window → Open Config Folder**.

### Can I add shortcuts for multiple apps in one file?

Each `.keyly` file should target one app (specified in the `# App:` header). Create separate files for different apps.

### How do I reload after editing configs?

Click the **⚙︎ button** in the shortcuts window and select **Reload Config**.

### Why doesn't the template work after installation?

Templates use default app paths that may not match your system. The app path can differ due to:
- Different installation methods (App Store vs direct download)
- Version-specific bundle names (e.g., `Cursor - Nightly.app`)
- Custom installation locations (`~/Applications/`)

**Fix:** Open the `.keyly` file in `~/.config/keyly/`, find the `# App:` line, and update it to your app's actual path.

See [Troubleshooting → Template Not Working](/troubleshooting/#template-not-working-after-installation) for detailed steps.

## Comparison

### How is Keyly different from CheatSheet?

Keyly is inspired by [CheatSheet](https://www.mediaatelier.com/CheatSheet) but:
- Reimplemented in Swift
- Adds custom shortcut configs via `.keyly` files
- [Community templates](/configuration/templates/) for popular apps
- Category descriptions with contextual hints
- Includes a settings menu
- Is open source
