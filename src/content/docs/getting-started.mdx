## Requirements

- **macOS 12.0+** (Monterey or later)
- Accessibility permissions

## Installation

<Steps>
1. Open any terminal app on your Mac (Terminal, iTerm, Warp, etc.)

2. Paste this command and press Enter:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install.sh | bash
   ```

3. Follow the on-screen instructions to grant Accessibility permission

4. Done! Double-tap `⇪ Caps Lock` to show shortcuts
</Steps>

## Setting Up Permissions

Keyly requires Accessibility permissions to:

1. **Monitor global keyboard events** — detect when you double-tap Caps Lock
2. **Read menu bar shortcuts** — extract shortcuts from other applications

<Steps>
1. Open **System Settings**
2. Go to **Privacy & Security → Accessibility**
3. Find **Keyly** in the list and enable it
4. Restart Keyly if needed
</Steps>

<Aside type="tip">
If Keyly doesn't appear in the list, try launching it first, then check again.
</Aside>

## Basic Usage

<Steps>
1. Run the app — you'll see a **K** icon in the menu bar
2. Open any application (Safari, VS Code, Finder, etc.)
3. Double-tap the **Caps Lock (⇪)** key
4. A floating window will appear showing all keyboard shortcuts
5. Start typing to filter the shortcuts — press ESC once to clear the search
6. Press ESC (again) or click outside to hide the window
</Steps>

## Menus

Click the **K icon** in your menu bar to access:

- **About Keyly** — Version and app info
- **Check for Updates...** — Look for a new version
- **Quit** — Exit Keyly

Click the **⚙︎ button** at the bottom-right of the shortcuts window to access:

- **Reload Config** — Reload your `.keyly` files
- **Open Config Folder** — Open the `~/.config/keyly/` folder
- **Open Accessibility Settings** — Quick link to grant permissions
- **Check for Updates...** — Look for a new version
- **Quit Keyly** — Exit Keyly
