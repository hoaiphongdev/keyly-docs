Master keyboard shortcuts and boost your macOS productivity with these tips.

## Start Small

Don't try to memorize all shortcuts at once. Pick 2-3 shortcuts per app that you use most often.

<Aside type="tip">
Use Keyly to discover which shortcuts exist, then focus on learning the ones you'll actually use.
</Aside>

## The 80/20 Rule

Focus on the 20% of shortcuts you'll use 80% of the time:

| Shortcut | Action |
|----------|--------|
| `⌘C` / `⌘V` | Copy / Paste |
| `⌘Z` | Undo |
| `⌘⇧Z` | Redo |
| `⌘Tab` | Switch apps |
| `⌘Space` | Spotlight search |
| `⌘W` | Close window/tab |
| `⌘Q` | Quit app |
| `⌘S` | Save |
| `⌘F` | Find |

## Learn by App

Pick one app you use daily and commit to using shortcuts for one week:

### Finder
- `⌘N` — New Finder window
- `⌘⇧N` — New folder
- `Space` — Quick Look
- `⌘⌫` — Move to Trash

### Safari / Chrome
- `⌘T` — New tab
- `⌘W` — Close tab
- `⌘L` — Focus address bar
- `⌘⇧T` — Reopen last tab

### VS Code / Editors
- `⌘P` — Quick open file
- `⌘⇧P` — Command palette
- `⌘D` — Select next occurrence
- `⌘/` — Toggle comment

## Build Muscle Memory

1. **See it** — Hold ⌘ for 2 seconds to view shortcuts with Keyly
2. **Use it** — Force yourself to use the shortcut instead of the mouse
3. **Repeat** — Do this for 3-5 days until it becomes automatic

- **Shortcut of the week** — Learn one new shortcut each week
- **Teach someone** — Teaching reinforces learning
