Keyly can be customized through `.keyly` configuration files stored in `~/.config/keyly/`.

## Config Location

All custom shortcut files are stored in:

```
~/.config/keyly/
```

You can quickly open this folder from the menu bar: **⌘ icon → Open Config**

## How It Works

1. Create a `.keyly` file in `~/.config/keyly/`
2. Define shortcuts with categories and key combinations
3. Keyly merges your custom shortcuts with the app's native ones
4. Hold ⌘ to see everything together

## Quick Example

Create a file `~/.config/keyly/safari.keyly`:

```
# Sheet Name: Safari Extras
# App: /Applications/Safari.app

[Navigation]
CMD+L       Open Location
CMD+T       New Tab
CMD+SHIFT+T Reopen Last Tab
```

See [Custom Shortcuts](/configuration/custom-shortcuts/) for the full syntax guide, or install [Templates](/configuration/templates/) for pre-made configs.
