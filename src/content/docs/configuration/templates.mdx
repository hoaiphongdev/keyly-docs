Templates are pre-made `.keyly` files created by the community for popular applications. Install them instantly with a single command.

## Quick Install

Use the template installer script to download templates from GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor
```

This installs the Cursor IDE template to `~/.config/keyly/cursor.keyly`.

<Aside type="caution" title="Template May Not Work Out of the Box">
Some templates may not work immediately because the **app path might be different** on your Mac.

App locations can vary due to:
- Different installation methods (App Store vs direct download)
- Version updates that change the app bundle name
- Custom installation paths

**If a template doesn't work after installation:**
1. Open the `.keyly` file in `~/.config/keyly/`
2. Find the `# App:` line at the top
3. Update it to match your app's actual location

```bash
# Find your app's correct path
ls /Applications/*.app
# Or for user-installed apps
ls ~/Applications/*.app
```

Example fix:
```keyly
# Before (template default)
# App: /Applications/Cursor.app

# After (your actual path)
# App: /Applications/Cursor - Nightly.app
```
</Aside>

## Template Installer Options

### Required Flags

| Flag | Description | Example |
|------|-------------|---------|
| `-t <name>` | Template name (required) | `-t cursor` |

### Optional Flags

| Flag | Description | Example |
|------|-------------|---------|
| `-n <filename>` | Custom local filename | `-n my-cursor.keyly` |
| `-f` | Force replace existing file | `-f` |

## Examples

### Basic Installation

```bash
# Install Cursor template
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor
```

### Custom Filename

```bash
# Install with custom name
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor -n cursor-custom.keyly
```

### Force Replace

```bash
# Replace existing file without prompt
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor -f
```

## What Happens

<Steps>
1. Script validates the template name
2. Downloads the template from GitHub
3. If file exists, prompts to backup or replace (unless `-f` is used)
4. Saves to `~/.config/keyly/`
5. Ready to use — hold ⌘ for 2 seconds to see shortcuts
</Steps>

## Template Format

Templates use the standard `.keyly` format with an additional feature: **category descriptions**.

```keyly
# Sheet Name: Cursor IDE
# App: /Applications/Cursor.app

[Chat]
> Focus on chat panel first.
CMD+L       Focus Chat
CMD+I       Open Composer
CMD+SHIFT+I Inline Composer

[Editor]
> Essential editing shortcuts.
CMD+D       Select Next Occurrence
CMD+SHIFT+L Select All Occurrences
```

The `> description` line after `[Category]` adds a helpful hint displayed below the category title in the shortcuts window.

## Creating Templates

Want to create a template for your favorite app?

<Steps>
1. Create a `.keyly` file following the [custom shortcuts syntax](/configuration/custom-shortcuts/)
2. Add category descriptions using `> hint text` for helpful context
3. Test it locally in `~/.config/keyly/`
4. Submit a PR to the [Keyly repository](https://github.com/hoaiphongdev/keyly)
</Steps>

### Template Guidelines

- Use clear, descriptive category names
- Add `> description` hints for context
- Include commonly used shortcuts
- Test with the actual application
- Follow the naming convention: `appname.keyly`
