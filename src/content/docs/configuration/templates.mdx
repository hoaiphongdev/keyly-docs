Templates are pre-made `.keyly` files created by the community for popular applications. Install them instantly with a single command.

## Quick Install

Use the template installer script to download templates from GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly
```

This installs the Cursor IDE template to `~/.config/keyly/templates/cursor.keyly`.

<Aside type="caution" title="If a Template Doesn't Show">
Keyly matches a template to its app by path, and by the app's name when the path is different on your Mac. That covers apps in `~/Applications`, apps from Setapp and newer yearly versions (a Photoshop 2024 template also shows in Photoshop 2025).

If your copy of the app has a different name, such as `Cursor - Nightly`:
1. Open the `.keyly` file in `~/.config/keyly/templates/`
2. Find the `# App:` line at the top
3. Change it to your app's name or bundle id

```keyly
# Before (template default)
# App: /Applications/Cursor.app

# After (your app's name)
# App: Cursor - Nightly
```

Anything Keyly can't read in the file is listed under **⚙︎ → ⚠︎ config problems** in the shortcuts window.
</Aside>

## Template Installer Options

### Required Flags

| Flag | Description | Example |
|------|-------------|---------|
| `-t <name>` | Template name (required) | `-t cursor.keyly` |

### Optional Flags

| Flag | Description | Example |
|------|-------------|---------|
| `-n <filename>` | Custom local filename | `-n my-cursor.keyly` |
| `-f` | Force replace existing file | `-f` |

## Examples

### Basic Installation

```bash
# Install Cursor template
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly
```

### Custom Filename

```bash
# Install with custom name
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly -n cursor-custom.keyly
```

### Force Replace

```bash
# Replace an existing file with the same name
curl -fsSL https://raw.githubusercontent.com/hoaiphongdev/keyly/main/scripts/install-templates.sh | bash -s -- -t cursor.keyly -f
```

## What Happens

<Steps>
1. Script validates the template name
2. Downloads the template from GitHub
3. If a file with the same name already exists, stops with an error and suggests `-f` (with `-f`, the file is replaced)
4. Saves to `~/.config/keyly/templates/`
5. Ready to use — double-tap Caps Lock to see shortcuts
</Steps>

## Template Format

Templates use the standard `.keyly` format with an additional feature: **category descriptions**.

```keyly
# Sheet Name: Cursor IDE
# App: Cursor

[Chat]
> Focus on chat panel first.
CMD+L       Focus Chat
CMD+I       Open Composer
CMD+SHIFT+I Inline Composer

[Editor]
> Essential editing shortcuts.
CMD+D       Select Next Occurrence
CMD+SHIFT+L Select All Occurrences
```

The `> description` line after `[Category]` adds a helpful hint displayed below the category title in the shortcuts window.

## Creating Templates

Want to create a template for your favorite app?

<Steps>
1. Create a `.keyly` file following the [custom shortcuts syntax](/configuration/custom-shortcuts/)
2. Add category descriptions using `> hint text` for helpful context
3. Test it locally in `~/.config/keyly/templates/`
4. Submit a PR to the [Keyly repository](https://github.com/hoaiphongdev/keyly)
</Steps>

### Template Guidelines

- Use clear, descriptive category names
- Add `> description` hints for context
- Include commonly used shortcuts
- Test with the actual application
- Follow the naming convention: `appname.keyly`
